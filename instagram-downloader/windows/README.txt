인스타그램 다운로더 (Windows 전용) — 단일 실행 파일

■ 실행 방법
- "인스타그램 다운로더.bat" 파일 하나만 있으면 됩니다. 더블클릭하면 실행됩니다.
  (PowerShell 코드가 이 .bat 안에 내장되어 있어 다른 파일이 필요 없습니다.)
- 별도 설치가 필요 없습니다. Windows 내장 PowerShell을 사용합니다.

■ 사용 방법
- 인스타그램 공개 게시물/릴스 링크를 입력창에 붙여넣고 [가져오기]를 누릅니다.
- 이미지·영상 미리보기가 표시되며, 각각 저장하거나 [이미지·영상 모두 저장]으로
  한 번에 내려받을 수 있습니다. (기본 저장 위치: 바탕화면\Instagram\게시물코드)
- 본문(캡션)은 복사하거나 .txt로 저장할 수 있습니다.

■ 참고
- 공개 계정의 게시물만 지원합니다(비공개·스토리 불가).
- 중계 서버 없이 인스타그램에 직접 접속하므로 안정적입니다.
- 처음 실행 시 Windows SmartScreen 경고가 뜨면 "추가 정보 -> 실행"을 누르세요.
- 검은 콘솔 창이 잠깐 뜬 뒤 프로그램 창이 나타납니다. 창을 닫으면 콘솔에
  "계속하려면 아무 키나..."가 표시되며, 아무 키나 누르면 종료됩니다.
- insta-downloader.ps1 은 사람이 읽기 쉬운 원본 소스입니다(실행에는 불필요).
- 이미지·글의 저작권은 원작성자에게 있으니 적법한 범위에서 사용하세요.
