인스타그램 다운로더 (Windows 전용)

■ 실행 방법
1) 이 폴더의 두 파일(인스타그램 다운로더.bat, insta-downloader.ps1)을
   반드시 같은 폴더에 둔 상태로 유지하세요.
2) "인스타그램 다운로더.bat" 파일을 더블클릭하면 프로그램 창이 열립니다.
   (별도 설치가 필요 없습니다. Windows 내장 PowerShell을 사용합니다.)

■ 사용 방법
- 인스타그램 공개 게시물/릴스 링크를 입력창에 붙여넣고 [가져오기]를 누릅니다.
- 이미지·영상 미리보기가 표시되며, 각각 저장하거나 [모두 저장]으로 한 번에
  내려받을 수 있습니다. (기본 저장 위치: 바탕화면\Instagram\게시물코드)
- 본문(캡션)은 복사하거나 .txt로 저장할 수 있습니다.

■ 참고
- 공개 계정의 게시물만 지원합니다(비공개·스토리 불가).
- 이 방식은 중계 서버 없이 인스타그램에 직접 접속하므로 안정적입니다.
- 처음 실행 시 Windows SmartScreen 경고가 뜨면 "추가 정보 → 실행"을 눌러
  진행하세요(인터넷에서 받은 파일에 대한 일반 경고입니다).
- 이미지·글의 저작권은 원작성자에게 있으니 적법한 범위에서 사용하세요.
