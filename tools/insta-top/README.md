# 인스타그램 인기 콘텐츠 정렬기

인스타그램 **계정 주소(또는 아이디)** 를 넣으면, 그 계정의 게시물을
**조회수 · 좋아요 순으로 내림차순 정렬**해 보여주는 프로그램입니다.

- 더블클릭하면 **브라우저에 조작 화면(UI)** 이 열립니다.
- 계정 주소를 붙여넣고 **[분석 시작]** 만 누르면 결과가 표로 나옵니다.
- **❤️ 좋아요순 / ▶️ 조회수순** 버튼으로 즉시 다시 정렬하고, **CSV 저장**도 됩니다.

---

## ⭐ 사용법 — 더블클릭 한 번

- **Windows**: `인기순정렬.bat` 더블클릭
- **Mac**: `인기순정렬.command` 더블클릭

그러면:

1. (처음 한 번만) 필요한 구성요소를 자동으로 설치합니다. — 수 분 소요
2. 잠시 후 **기본 브라우저에 조작 화면**이 자동으로 열립니다.
3. 분석할 **계정 주소**(예: `https://www.instagram.com/instagram/`)를 붙여넣고 **[분석 시작]** 클릭.
4. **처음 실행 때 딱 한 번만 인스타그램 로그인 창**이 함께 열립니다. 거기서 로그인하면,
   로그인 정보가 브라우저 프로필 폴더(`ig-profile/`)에 저장되어
   **이후에는 창 없이 자동 로그인**됩니다. (로그인이 만료되면 그때만 창이 다시 뜹니다.)
5. 결과 표가 나오면 정렬 버튼으로 원하는 기준으로 보고, 필요하면 CSV로 저장하세요.

> 사용을 마치려면 검은색 **명령 창을 닫으면** 프로그램이 종료됩니다.

> **딱 하나만 미리** — 컴퓨터에 **Node.js**가 없으면 실행 파일이 설치 사이트(https://nodejs.org)를 자동으로 열어줍니다.
> LTS 버전을 설치한 뒤 실행 파일을 다시 더블클릭하세요. (한 번만 하면 됩니다.)
>
> Mac에서 "확인되지 않은 개발자" 경고가 뜨면: 파일 **우클릭 → 열기 → 열기**를 선택하세요.

## 화면에서 할 수 있는 것

| 항목 | 설명 |
|------|------|
| **분석할 계정** | 프로필 주소나 아이디(`@instagram` 또는 `instagram`) |
| **가져올 게시물 수** | 최근 30 / 60 / 100 / 200개 중 선택 |
| **기본 정렬 기준** | 좋아요순 또는 조회수순 |
| **자동 로그인 정보(선택)** | 아이디/비밀번호를 넣으면 로그인 창 없이 자동 로그인. 비워두면 창에서 직접 로그인 |
| **결과 표** | 썸네일 · 유형(사진/동영상/릴스/앨범) · 조회수 · 좋아요 · 댓글 · 게시일 · 캡션 |
| **CSV 저장** | 결과를 엑셀에서 열 수 있는 CSV 파일로 내려받기 |
| **로그인 초기화** | 저장된 로그인 세션을 지우고 다시 로그인 |

---

## 결과 보는 법 / 정렬

- 결과 표 위의 **❤️ 좋아요순 · ▶️ 조회수순** 버튼으로 정렬 기준을 즉시 바꿀 수 있습니다.
- **조회수는 릴스·동영상에만** 존재합니다. 사진/앨범 게시물은 조회수가 없어 `-` 로 표시됩니다.
- 썸네일이나 캡션을 클릭하면 해당 게시물의 인스타그램 페이지로 이동합니다.

## 직접 명령어로 실행하기 (개발자용, 선택)

1. **Node.js 설치** — https://nodejs.org 에서 LTS 버전 설치
2. 이 폴더(`tools/insta-top`)에서 명령창(cmd/터미널)을 엽니다.
3. 아래 명령으로 설치 후 실행:
   ```
   npm install playwright
   npx playwright install chromium
   node server.js       # GUI 서버 → http://127.0.0.1:8787 접속
   ```
- **UI 없이 파일로만** 뽑고 싶다면 `config.json` 을 채운 뒤 `node insta-top.js` 를 실행하면
  같은 폴더에 `report.html` · `report.csv` 가 생성됩니다.

### 파일 구성

| 파일 | 설명 |
|------|------|
| `인기순정렬.bat` / `.command` | 더블클릭 실행 런처 (서버 실행 + 브라우저 자동 열기) |
| `server.js` | 로컬 GUI 서버 (조작 화면 제공 + 분석 실행/진행상황 전송) |
| `ui.html` | 브라우저에 열리는 조작 화면 |
| `insta-top.js` | 핵심 로직(로그인·수집·정렬) + CLI |
| `config.json` | CLI(`node insta-top.js`)용 설정 |

## 참고 / 한계

- **조회수는 릴스·동영상에만** 존재합니다. 사진/앨범은 조회수가 제공되지 않아 `-` 로 표시됩니다.
- **비공개 계정**은 내 로그인 계정이 **팔로우**하고 있어야 게시물을 볼 수 있습니다.
- **좋아요 수를 숨긴** 게시물은 정확한 수가 나오지 않을 수 있습니다.
- 인스타그램은 자동화 접근을 제한하므로, 짧은 시간에 여러 번 실행하면 데이터가 비어 보일 수 있습니다. 그럴 땐 **잠시 후 다시 실행**하세요.
- 이 프로그램은 **내 컴퓨터에서만** 동작하는 로컬 도구이며, 입력한 로그인 정보는 외부로 전송되지 않습니다. 인스타그램 이용약관과 관련 법규를 준수해 개인적·정당한 범위에서 사용하세요.
