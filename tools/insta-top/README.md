# 인스타그램 인기 콘텐츠 정렬기

인스타그램 **계정 주소(또는 아이디)** 를 넣으면, 그 계정의 게시물을
**조회수 · 좋아요 순으로 내림차순 정렬**해 보기 좋은 **HTML 리포트**와 **CSV**로 정리해 줍니다.

- 릴스·동영상은 **조회수**, 모든 게시물은 **좋아요/댓글**을 함께 보여줍니다.
- 리포트에서 **❤️ 좋아요순 / ▶️ 조회수순** 버튼으로 즉시 다시 정렬할 수 있습니다.

---

## ⭐ 가장 쉬운 방법 — 더블클릭 실행

명령어를 칠 필요 없이 **파일을 더블클릭**만 하면 됩니다.

- **Windows**: `인기순정렬.bat` 더블클릭
- **Mac**: `인기순정렬.command` 더블클릭

처음 한 번은 필요한 구성요소를 자동으로 설치하고(수 분 소요), 이후에는 바로 실행됩니다.
끝나면 결과(`report.html`)가 자동으로 열립니다.

> **딱 하나만 미리** — 컴퓨터에 **Node.js**가 없으면 실행 파일이 설치 사이트(https://nodejs.org)를 자동으로 열어줍니다.
> LTS 버전을 설치한 뒤 실행 파일을 다시 더블클릭하세요. (한 번만 하면 됩니다.)
>
> Mac에서 "확인되지 않은 개발자" 경고가 뜨면: 파일 **우클릭 → 열기 → 열기**를 선택하세요.

## 1) 분석할 계정 정하기 — `config.json`

`config.json` 파일을 메모장으로 열어 **`profile`** 값만 바꾸면 됩니다.

```json
{
  "profile": "https://www.instagram.com/instagram/",
  "username": "",
  "password": "",
  "maxPosts": 60,
  "sortBy": "likes",
  "delayMs": 1200
}
```

| 항목 | 설명 |
|------|------|
| `profile` | **분석할 계정** — 프로필 주소나 아이디(예: `instagram` 또는 `@instagram`) |
| `username` / `password` | **내 로그인 계정** (자동 로그인용, 선택) — 비워두면 창에서 직접 로그인 |
| `maxPosts` | 최대 몇 개의 게시물을 모을지 (기본 60) |
| `sortBy` | 리포트 기본 정렬 — `"likes"`(좋아요순) 또는 `"views"`(조회수순) |
| `delayMs` | 요청 사이 지연(ms) — 너무 빠르면 제한될 수 있어 여유를 둡니다 |

> 인스타그램은 **로그인**이 있어야 게시물 데이터를 안정적으로 볼 수 있습니다.
> `username`/`password`를 넣기 싫다면 비워 두세요. 실행 시 브라우저 창이 열리고
> 직접 로그인하면 됩니다. 한 번 로그인하면 세션(`ig-session.json`)이 저장돼 다음부터는 바로 실행됩니다.

## 직접 명령어로 실행하기 (선택)

1. **Node.js 설치** — https://nodejs.org 에서 LTS 버전 설치
2. 이 폴더(`tools/insta-top`)에서 명령창(cmd/터미널)을 엽니다.
3. 아래 명령으로 설치 후 실행:
   ```
   npm install playwright
   npx playwright install chromium
   node insta-top.js
   ```
- 로그인 창을 직접 보며 진행하려면:
  - Windows: `set HEADLESS=false && node insta-top.js`
  - Mac/Linux: `HEADLESS=false node insta-top.js`
- 끝나면 같은 폴더에 **`report.html`** 과 **`report.csv`** 가 생성됩니다.

## 결과 보는 법

| 열 | 의미 |
|----|------|
| # | 정렬 순위 |
| 썸네일 | 게시물 이미지(클릭하면 인스타그램으로 이동) |
| 유형 | 사진 · 동영상 · 릴스 · 앨범 |
| 조회수 | **릴스·동영상만** 표시 (사진/앨범은 `-`) |
| 좋아요 / 댓글 | 수집 시점 기준 수치 |
| 게시일 | 게시물 업로드 날짜 |

리포트 상단의 **❤️ 좋아요순 / ▶️ 조회수순** 버튼으로 즉시 다시 정렬할 수 있습니다.

## 참고 / 한계

- **조회수는 릴스·동영상에만** 존재합니다. 사진/앨범 게시물은 조회수가 제공되지 않아 `-` 로 표시됩니다.
- **비공개 계정**은 내 로그인 계정이 **팔로우**하고 있어야 게시물을 볼 수 있습니다.
- **좋아요 수를 숨긴** 게시물은 정확한 수가 나오지 않을 수 있습니다.
- 인스타그램은 자동화 접근을 제한하므로, 짧은 시간에 여러 번 실행하면 데이터가 비어 보일 수 있습니다. 그럴 땐 **잠시 후 다시 실행**하거나 `delayMs` 값을 늘리세요.
- 이 도구는 인스타그램 웹의 공개 데이터를 본인 로그인으로 조회하는 용도입니다. 인스타그램 이용약관과 관련 법규를 준수해 개인적·정당한 범위에서 사용하세요.
