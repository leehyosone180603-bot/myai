# KHFF 위생교육 자동 다음 재생

한국건강기능식품협회 위생교육센터(`edu.khff.or.kr`)에서 **한 차시 영상이 끝나면 자동으로 "다음" 강의로 넘어가 재생**되게 해 주는 스크립트입니다. 매 차시마다 "다음" 버튼을 직접 누를 필요가 없어집니다.

> 참고: 이 스크립트는 영상이 **정상적으로 끝났을 때** 다음 버튼을 눌러 줄 뿐, 영상을 빨리 감거나 진도를 건너뛰지는 않습니다.

---

## 방법 1. Tampermonkey (권장 · 한 번 설치하면 계속 작동)

1. 브라우저에 **Tampermonkey** 확장 프로그램을 설치합니다.
   - Chrome / Edge: 웹스토어에서 "Tampermonkey" 검색 후 설치
2. Tampermonkey 아이콘 → **"새 스크립트 추가"** 클릭
3. 편집기에 있는 내용을 모두 지우고, [`khff-auto-play.user.js`](./khff-auto-play.user.js) 파일 내용을 **전부 복사해 붙여넣기**
4. `Ctrl + S` (또는 파일 → 저장)로 저장
5. `edu.khff.or.kr` 강의 페이지를 새로고침하면 자동 작동합니다.

설치 후에는 강의 페이지에 들어갈 때마다 자동으로 켜지며, 영상이 끝나면 약 1.5초 뒤 "다음" 강의로 넘어가 재생을 시작합니다.

---

## 방법 2. 개발자도구 콘솔 (설치 없이 즉시 사용 · 새로고침하면 사라짐)

1. 강의 재생 페이지에서 `F12`를 눌러 개발자도구를 엽니다.
2. **Console(콘솔)** 탭을 클릭합니다.
3. [`khff-auto-play.user.js`](./khff-auto-play.user.js) 파일에서 `(function () { ... })();` **본문 부분**(맨 위 `// ==UserScript==` 주석 블록은 빼도 됩니다)을 복사해 콘솔에 붙여넣고 `Enter`.
4. `[KHFF-AUTO] 활성화 완료` 메시지가 뜨면 작동 중입니다.

> 콘솔 방식은 페이지를 새로고침하거나 다음 페이지로 URL이 완전히 바뀌면 다시 붙여넣어야 할 수 있습니다. 계속 쓰려면 방법 1(Tampermonkey)을 권장합니다.

---

## 동작 방식 (이 사이트의 실제 흐름에 맞춤)

이 사이트는 한 구간(인트로 · 학습목표 · 도입 · 본문 · 학습정리 등)이 끝날 때마다 다음과 같이 동작합니다. 스크립트는 이 흐름을 그대로 자동화합니다.

1. **영상이 끝나면 "안내" 팝업**이 뜹니다 → *"…학습이 완료되었습니다. 확인 버튼을 클릭하면 다음 학습으로 이동합니다."*
   → 스크립트가 이 팝업의 **"확인"** 버튼을 자동으로 누릅니다. (옆의 **"취소"** 는 절대 누르지 않습니다.)
2. **다음 구간으로 넘어가면** 영상 가운데에 **재생(▶) 버튼**이 있는 정지 상태입니다.
   → 스크립트가 먼저 `video.play()` 로 재생을 시도하고, 안 되면 **영상 가운데 재생버튼을 좌표로 클릭**해 재생을 시작합니다.
3. 자동재생이 브라우저 정책으로 막히면 **잠깐 음소거로 재생 후 소리를 복원**합니다.
4. 팝업 등장·영상 교체를 `MutationObserver`로 계속 감시하고, 1.5초마다 팝업이 떠 있는지도 확인합니다.

> 참고: 팝업은 누르지 않아도 "7초 후" 자동으로 넘어가지만, 스크립트가 "확인"을 눌러 더 빨리 넘어갑니다.

## 설정 바꾸기

`khff-auto-play.user.js` 상단의 `CONFIG` 값을 조정할 수 있습니다.

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| `delayBeforeConfirmMs` | `800` | 완료 팝업이 뜬 뒤 "확인"을 누르기까지 대기 시간(ms). |
| `confirmButtonTexts` | `['확인']` | 다음으로 넘기는 팝업 버튼 문구. |
| `denyButtonTexts` | `['취소', ...]` | 절대 누르지 않을 문구. |
| `playRetryMax` | `20` | 새 영상 재생 시도 최대 횟수. |
| `debug` | `true` | 콘솔 로그 표시 여부. `false`로 끄면 조용히 작동합니다. |

## 문제 해결

- **다음으로 안 넘어가요**: 콘솔(F12)에 `[KHFF-AUTO] 완료 팝업 감지` 로그가 안 보이면, 팝업의 실제 버튼 문구가 "확인"이 아닐 수 있습니다. `confirmButtonTexts`에 문구를 추가하세요.
- **영상이 자동재생 안 돼요**: 콘솔에 `가운데 재생버튼 클릭 시도` 로그가 보이는데도 재생이 안 되면, 재생버튼 위치가 영상 정중앙이 아닐 수 있습니다. 이 경우 페이지에서 아무 곳이나 한 번 클릭한 뒤 사용하면 자동재생 차단이 풀립니다.
- **소리가 안 나요**: 자동재생 우회로 음소거되었다가 복원되는데, 실패하면 플레이어의 음소거 버튼을 한 번 눌러 주세요.
- **차시가 바뀔 때 멈춰요**: 강의(lesson) 번호가 바뀌면서 페이지가 완전히 새로고침되면, **콘솔 방식은 다시 붙여넣어야** 합니다. 이런 경우 **Tampermonkey(방법 1)** 를 쓰면 페이지가 바뀌어도 자동으로 계속 작동합니다.
