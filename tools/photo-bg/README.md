# 제품 사진 배경 변환기

제품 사진을 올리면 **배경을 자동으로 지우고**, 흰색·회색·베이지 등 원하는 색으로 바꿔
**내 컴퓨터에 바로 저장**하는 프로그램입니다. 홈페이지(calcbox.kr)와는 무관한 별도 도구입니다.

- 설치 필요 없음 · 인터넷 연결 필요 없음 · 회원가입 없음
- 사진이 외부로 전송되지 않습니다 (내 컴퓨터 브라우저 안에서만 처리)
- 배경 변환 · **사진 자르기** · 복사한 사진 **붙여넣기(Ctrl+V)** 지원

## ⭐ 실행 방법

- **Windows**: `실행하기.bat` 더블클릭 (또는 `배경변환기.html` 을 그냥 더블클릭)
- **Mac**: `실행하기.command` 더블클릭 (경고 시 우클릭 → 열기 → 열기)

기본 브라우저(크롬·엣지 등)에서 프로그램 창이 열립니다.
`배경변환기.html` 파일 하나만 있으면 동작하므로, 바탕화면이나 USB에 복사해서 써도 됩니다.

## 사용 순서

1. **사진 올리기** — 세 가지 방법 모두 됩니다. 올리는 즉시 배경을 자동으로 인식합니다.
   - 사진 파일을 창 안으로 **끌어다 놓기** (탐색기·바탕화면에서 복사한 파일도 가능)
   - `[사진 선택하기]` 버튼으로 고르기
   - **복사한 이미지를 `Ctrl+V` 로 붙여넣기** — 웹페이지의 사진을 우클릭 → '이미지 복사',
     캡처 도구(`Win+Shift+S`)로 캡처, 탐색기에서 이미지 파일 복사 모두 바로 불러옵니다.
     (`📋 복사한 사진 붙여넣기` 버튼을 눌러도 됩니다)
2. **자르기(필요할 때만)** — `자르기 시작` 을 누르면 사진 위에 선택 사각형이 생깁니다.
   - 사각형 안쪽을 끌어 **이동**, 모서리·변의 손잡이를 끌어 **크기 조절**, 바깥 빈 곳을 끌면 **새로 지정**
   - 비율: `자유` `1:1` `4:3` `3:4` `16:9`
   - `제품에 맞춰` 를 누르면 배경을 지운 제품 영역에 딱 맞게 범위를 잡아 줍니다.
   - `잘라내기 적용`(Enter)으로 자르고, `취소`(Esc)로 그만둡니다. `초기화` 를 누르면 원래 사진으로 돌아옵니다.
3. **배경 색 고르기** — `배경 지우기(투명)` · 흰색 · 연회색 · 회색 · 진회색 · 베이지 ·
   아이보리 · 크래프트 · 연핑크 · 민트 · 하늘 · 검정 버튼을 누르면 배경이 바로 바뀝니다.
   `직접 선택` 으로 원하는 색을 골라도 됩니다.
4. **다듬기(필요할 때만)**
   - **배경 인식 강도** — 배경이 남으면 올리고, 제품이 지워지면 내립니다. (그림자까지 지우려면 높게)
   - **가장자리 부드럽게** — 경계의 톱니와 흰 테두리를 정리합니다.
   - **지우개 / 복원 브러시** — 남은 배경이나 잘못 지워진 부분을 마우스로 칠해 고칩니다.
   - `되돌리기`(Ctrl+Z) · `원본 보기`(누르고 있는 동안) · `초기화`
5. **저장** — `💾 내 컴퓨터에 저장`(Ctrl+S)을 누르면 **다운로드 폴더**에 파일이 저장됩니다.
   `배경색 8종 한 번에 저장` 을 누르면 투명·흰색·회색 등 8장이 한꺼번에 저장됩니다.

저장 파일 이름은 `원래이름_배경-흰색.png` 형태로 만들어집니다.

## 저장 옵션

| 항목 | 값 | 설명 |
|------|-----|------|
| 파일 형식 | **PNG** | 투명 배경을 지원합니다. 배경을 지웠다면 반드시 PNG. |
| | **JPG** | 용량이 작습니다. 투명은 지원하지 않아 흰 배경으로 저장됩니다. |
| 크기 | **원본 크기** | 올린 사진 그대로 저장합니다. |
| | **1000 × 1000 / 1500 × 1500 정사각** | 제품을 가운데 정렬하고 여백을 맞춘 정사각 이미지로 저장합니다. 쇼핑몰 썸네일용. |

> 저장 위치를 바꾸려면 브라우저 설정에서 다운로드 폴더를 지정하거나,
> "다운로드 전에 각 파일의 저장 위치 확인" 옵션을 켜면 매번 폴더를 고를 수 있습니다.

## 잘 지워지는 사진 / 어려운 사진

배경 인식은 **사진 테두리에서 시작해 비슷한 색이 이어지는 범위**를 배경으로 봅니다.

- 잘 됨: 흰 전지·단색 천 위에서 찍은 사진, 제품과 배경의 밝기 차이가 뚜렷한 사진
- 어려움: 배경과 제품 색이 비슷한 경우(흰 접시 + 흰 테이블), 털·머리카락·투명 유리,
  배경이 복잡한 생활 공간 사진 → 강도를 조절하고 브러시로 다듬으면 대부분 해결됩니다.

## 참고

- 큰 사진은 처리 속도를 위해 긴 변 2600px 로 줄여서 작업합니다.
- 크롬·엣지·사파리 최신 버전에서 동작합니다. (인터넷 익스플로러 미지원)
