# vidIQ 고득점 영상 수집기 🔴

주제(예: **첫사랑 잊는 법**)를 입력하면 유튜브에서 검색해, vidIQ 크롬 확장의
**빨간 배지(예: `18.8x`)에 해당하는 "아웃라이어 배수"** 를 계산하고,
**100에 가까운 높은 배수의 영상들만 골라 배수 높은 순으로** 정리해 줍니다.

영상별로 아래 데이터를 모읍니다.

- 🔗 영상 링크
- 🖼 영상 썸네일
- 📝 영상 제목
- 📄 영상 설명글
- 💬 좋아요가 많은 댓글 5개

결과는 보기 좋은 **`report.html`** 리포트와 **`results.json` / `results.csv`** 로 저장됩니다.

---

## ⭐ 가장 쉬운 방법 — 더블클릭 실행

명령어를 칠 필요 없이 **파일을 더블클릭**만 하면 됩니다.

- **Windows**: `수집실행.bat` 더블클릭
- **Mac**: `수집실행.command` 더블클릭

처음 실행하면 주제를 물어보고, 끝나면 결과(`report.html`)가 자동으로 열립니다.

> **딱 두 가지만 미리 준비**
> 1. 컴퓨터에 **Node.js** (없으면 실행 파일이 설치 사이트를 자동으로 열어줍니다. LTS 설치 후 다시 더블클릭)
> 2. **YouTube Data API 키** — 아래 "API 키 발급" 참고 (한 번만 발급받아 `config.json`에 붙여넣기)

---

## 🔑 YouTube Data API 키 발급 (한 번만)

이 프로그램은 **공식 YouTube Data API v3** 로 데이터를 가져옵니다. 무료이며 하루 사용량도 넉넉합니다.

1. https://console.cloud.google.com 접속 → 프로젝트 만들기(아무 이름)
2. **API 및 서비스 → 라이브러리** 에서 **"YouTube Data API v3"** 검색 → **사용 설정**
3. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**
4. 만들어진 키(문자열)를 복사해서 `config.json` 의 `"apiKey"` 값에 붙여넣기

---

## ⚙️ 설정 바꾸기 (`config.json`)

메모장으로 열어 수정하세요.

```json
{
  "apiKey": "발급받은_API_키",
  "topic": "첫사랑 잊는 법",   // 검색할 주제 (실행할 때 직접 입력하면 이 값보다 우선)
  "searchResults": 30,          // 검색해서 살펴볼 영상 개수 (많을수록 오래 걸림)
  "minMultiplier": 5,           // 이 배수 이상만 결과에 포함 (숫자를 높이면 더 대박 영상만)
  "channelSampleSize": 15,      // 채널 평소 조회수를 잴 때 볼 최근 영상 개수
  "topComments": 5,             // 영상별로 모을 "좋아요 많은 댓글" 개수
  "regionCode": "KR",
  "relevanceLanguage": "ko"
}
```

- **더 대박(높은 배수) 영상만 보고 싶다면** `minMultiplier` 를 `20`, `50` 처럼 올리세요.

## 직접 명령어로 실행하기 (선택)

Node.js가 설치돼 있으면 별도 설치 없이 바로 실행됩니다(외부 라이브러리 불필요).

```bash
node collect.js                 # config.json 의 topic 사용
node collect.js "첫사랑 잊는 법"   # 주제를 바로 입력
```

끝나면 같은 폴더에 `report.html`, `results.json`, `results.csv` 가 생성됩니다.

## 🔴 "18.8x" 숫자는 어떻게 나온 건가요? (중요)

vidIQ가 썸네일 위에 보여 주는 **빨간 `N배(x)` 배지**는 그 크롬 확장만 아는
**비공개(사내) 값**이라 어떤 공개 API로도 그대로 가져올 수 없습니다.

하지만 그 배지가 뜻하는 것은 결국 **"이 영상이 채널 평소 조회수의 몇 배로 터졌는가"**
(과대성과 · 아웃라이어)입니다. 그래서 이 프로그램은 공식 YouTube Data API로
같은 개념을 **그대로 재현**합니다.

```
아웃라이어 배수 = 영상 조회수 ÷ 채널 최근 영상들의 조회수 중앙값
```

- `1배` = 채널 평소 수준
- `18.8배` = 평소의 18.8배로 터진 영상
- `100배 ≈` 채널 규모 대비 초대박 아웃라이어

> 채널 정보를 못 구하는 경우엔 **구독자수 대비**로 근사 계산하며, 리포트에 그 사실을 표시합니다.
> vidIQ의 실제 숫자와 완전히 동일하지는 않지만, "높은 숫자 = 채널 대비 크게 터진 영상"이라는
> **판단 기준은 동일**합니다.

## 결과 보는 법 (`report.html`)

배수 높은 순으로 카드가 정렬됩니다. 카드마다:

| 항목 | 설명 |
|------|------|
| 배지 `N x` | 아웃라이어 배수 (색: 회색<초록<노랑<주황<빨강 순으로 높음) |
| 썸네일 | 클릭하면 유튜브 영상으로 이동 |
| 제목 | 클릭하면 유튜브 영상으로 이동 |
| 설명글 보기 | 펼치면 영상 설명글 전체 표시 |
| 좋아요 많은 댓글 5개 | 좋아요 수와 함께 상위 댓글 표시 |

## 참고 / 한계

- YouTube Data API **하루 사용량(쿼터)** 은 기본 10,000 단위입니다. 검색 1회당 100 단위를 쓰므로
  하루 수십 번 실행에는 충분합니다. 초과 시 다음 날 초기화됩니다.
- 댓글이 꺼져 있거나 없는 영상은 댓글 칸이 비어 표시됩니다.
- 조회수·좋아요·댓글 수치는 실행 시점 기준이며 실시간으로 바뀝니다.
